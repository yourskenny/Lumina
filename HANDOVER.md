# Lumina Project Handover

## 🚨 Current Status
The application is **Functionally Stable** but **User Experience may vary**.
- **Crash Issues**: Resolved. The notorious "Mic Click Crash" was fixed by moving `IntentDispatcher` logic to `Dispatchers.IO` and adding robust error handling.
- **Vision (YOLO)**: The model has been replaced with `yolov8n` (VOC 20 classes). The code now dynamically adapts to model output dimensions.
- **Agent**: The `AgentService` (LangChain) is integrated and protected against initialization failures.

## 🛠️ Key Fixes Applied
1.  **Threading**: All heavy operations (Agent, Location, DB) are strictly enforced on `Dispatchers.IO`.
2.  **Model Compatibility**: `ObjectDetector` now supports both 84-channel (COCO) and 24-channel (VOC) models dynamically.
3.  **Error Boundaries**: Added `try-catch` blocks around critical service calls (`AgentService`, `LocationService`, `IntentDispatcher`).

## ⚠️ Known Issues / Limitations
1.  **Model Quality**: The current `yolov8n_relu_20class_zq.onnx` might have low confidence for certain objects.
    - *Recommendation*: Replace with a standard `yolov8n.onnx` (COCO 80 classes) for better results.
2.  **Network Latency**: The Agent response might be slow due to network conditions connecting to DashScope.
3.  **Permissions**: On some devices (e.g., Xiaomi), aggressive background killing might stop the app. Ensure "Autostart" and "Background Popup" permissions are granted.

## 📝 Debugging Guide
If issues persist:
1.  **Logcat**: Filter for `tag:CameraViewModel` or `tag:ObjectDetector`.
2.  **Crash**: Look for `AndroidRuntime` errors. If no crash log is visible but app disappears, suspect ANR or System Kill (OOM).
